# Quiet Protocol

Spy stealth-lite third-person prototype.

## Play

1. Install [Godot 4.7+](https://godotengine.org/) (already via winget if set up here).
2. Open this folder in Godot (`project.godot`).
3. Press **F5**.

## Goal

Start on **L1 Lobby**. Take **stairs** (west) or **lifts** (east) to **L3**, steal the dossier, reach **Extract**. Stay Ghost if you can.

## Characters

Low-poly characters from [Kenney.nl](https://kenney.nl) (CC0):
- Player skin: Animated Characters Protagonists (`criminalMaleA`)
- Guards skin: Animated Characters Retro (`humanMaleA`)

## Environment

Furniture props from [Kenney Furniture Kit](https://kenney.nl/assets/furniture-kit) (CC0).

## Controls

| Key | Action |
|-----|--------|
| WASD | Move |
| Mouse | Look |
| Ctrl | Crouch |
| Shift | Sprint (noisy) |
| E | Silent takedown / interact |
| F | Throw coin distraction |
| LMB | Shoot (alerts nearby) |
| R | Restart |
| Esc | Free / capture mouse |

## Grades

- **GHOST** — never compromised or loud
- **COMPROMISED** — spotted / suspicious alert
- **LOUD** — gunfire / full alert
